# Foodsa – Restaurant Website

Foodsa is a modern, responsive restaurant website template designed for restaurants, cafés, and food businesses. It includes menu browsing, food categories, item details, gallery previews, reservation UI, and contact sections.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Navigation bar with scroll effects and active section links
- Smooth scrolling and mobile navigation
- Search overlay with food category shortcuts and trending tags
- Food category filtering
- Interactive food menu cards
- Food details popup with image, price, rating, preparation time, and quantity controls
- Add-to-cart counter interaction
- Image gallery with previous and next navigation
- Testimonial slider powered by Swiper
- Magnific Popup integration for iframe content
- Scroll animations using AOS
- Countdown timer
- Animated number counters
- Newsletter subscription interface
- Reservation and contact form feedback UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
- Font Awesome
- AOS (Animate On Scroll)
- Swiper.js
- Magnific Popup

## Installation

1. Download or copy the Foodsa project folder.
2. Keep the `index.html`, `css`, `js`, and `img` files in the correct locations.
3. Open the project folder in Visual Studio Code.
4. Run `index.html` using the Live Server extension, or open it in your browser.
5. Check the browser Console and Network tabs for missing files or JavaScript errors.

## Customization

You can customize the following elements:

- Restaurant name and logo
- Hero banner and background images
- Food menu items, prices, and descriptions
- Food categories
- Gallery images
- Restaurant contact details
- Opening hours
- Reservation and contact sections
- Colors, typography, and layout styles

## Important Notes

The reservation, contact, newsletter, and cart interactions in the shared JavaScript are currently front-end demonstrations.

To make them work as real services, you will need to connect:
- A backend reservation system
- A contact form submission handler
- An email marketing or newsletter service
- A shopping cart and checkout system
